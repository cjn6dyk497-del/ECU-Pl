# KWP2000 — canais de medição da DDE

O modo OBD2 genérico lê os PIDs legislados: oito valores, iguais em qualquer
carro. O KWP2000 fala directamente com a DDE e dá acesso aos blocos de medição
internos, onde vive o que interessa para diagnóstico — **valor pedido contra
valor medido**.

## Porque é que o mapa vem vazio

A lista `MEAS` no `server.py` está vazia de propósito.

Os identificadores de bloco e a posição de cada valor dentro deles são
específicos de cada centralina, e vivem nos ficheiros SGBD da BMW. Preenchê-la
com números inventados daria leituras plausíveis e erradas — pior do que não
ter nada. O que o servidor traz são as ferramentas para os descobrires.

## Antes de começar

O *fast init* depende de janelas de 25 ms. O FTDI vem de fábrica com um
*latency timer* de 16 ms, o que chega para estragar o temporizado.

```bash
# macOS — confirma o valor actual
ioreg -r -c IOSerialBSDClient -l | grep -i latency
```

Se estiver acima de 1 ms, corrige-o antes de continuares. Sem isto, a
inicialização falha de forma intermitente e vais perder tempo a perseguir um
problema que não é do protocolo.

## Descoberta, passo a passo

### 1. Passar para modo KWP2000

```bash
curl -X POST "localhost:8000/mode/kwp?addr=0x12&init=fast"
```

O `0x12` é o endereço habitual da DDE. Se não pegar, o servidor volta sozinho
a OBD2 e diz-o na consola — nesse caso experimenta `init=slow`, ou outro
endereço.

Confirma:

```bash
curl localhost:8000/mode
```

### 2. Confirmar que estás a falar com a centralina certa

```bash
curl localhost:8000/kwp/ecuid
```

Devolve o número de peça e a versão em ASCII. Se isto responder, a sessão está
de pé.

### 3. Descobrir que blocos existem

```bash
curl -X POST localhost:8000/kwp/scan
```

Percorre os 255 identificadores. Demora alguns minutos — é um pedido por
identificador. Devolve os que responderam, com o conteúdo em hexadecimal.

Para varrer só uma parte:

```bash
curl -X POST "localhost:8000/kwp/scan?lo=0x01&hi=0x40"
```

### 4. Identificar os canais dentro de cada bloco

É aqui que está o trabalho de verdade. Escolhe um bloco e lê-o:

```bash
curl localhost:8000/kwp/lid/0x0B
```

Devolve o bloco em hexadecimal e, para cada posição, as leituras possíveis:
byte simples, e dois bytes com e sem sinal.

**Com o motor a trabalhar, acelera e volta a ler.** O valor que acompanhar as
rotações diz-te o offset e o tamanho do canal. A escala tira-se por regra de
três: se às 800 rpm o valor for 3200, a escala é 0,25.

Vale a pena fazer isto com o motor quente e frio, ao ralenti e a acelerar —
canais como a temperatura só se distinguem assim.

### 5. Escrever no mapa

Cada linha do `MEAS` é:

```python
(nome, lid, offset, tamanho, com_sinal, escala, offset_valor, unidade)
```

Por exemplo, depois de descobrires que o bloco `0x0B` traz as rotações em dois
bytes na posição 0, sem sinal, a 0,25 rpm por incremento:

```python
MEAS = [
    ("rpm_dde", 0x0B, 0, 2, False, 0.25, 0.0, "rpm"),
]
```

Reinicia o servidor e o canal passa a aparecer no WebSocket.

Blocos com vários canais são lidos uma só vez por ciclo, mesmo que tenhas
várias linhas a apontar para o mesmo `lid`.

## Canais que compensa procurar

| Canal | Para que serve |
|---|---|
| Pressão do rail, pedida e real | Distingue sensor avariado de bomba gasta |
| Massa de ar, pedida e real | Distingue MAF sujo de EGR encravado |
| Pressão de turbo, pedida e real | Com o comando VNT, fecha o diagnóstico do P0299 |
| **Correcção por injector** | Identifica o cilindro do P0263 sem teste de retorno |
| Posição EGR, pedida e real | Confirma se a válvula obedece ao comando |
| Estado das velas | Confirma o P0380 sem desmontar nada |

A correcção por injector é a mais valiosa: são quatro valores, um por cilindro,
e o que se afastar dos outros é o injector gasto. É o que transforma o painel
de diagnóstico de explicação em ferramenta.

## Apagar avarias

```bash
curl -X POST localhost:8000/kwp/cleardtc
```

Serviço `0x14`, grupo `0xFF00`. Não precisa de *security access*.

## O que fica de fora

Escrever adaptações, códigos IMA de injectores ou gravar o flash exige passar o
serviço `0x27` — um handshake *seed/key* cuja função é específica da BMW e não
está publicada. Vive dentro dos SGBD do EDIABAS.

Para isso não há atalho: ou se usa o EDIABAS, ou uma reimplementação como o
EDIABASLib. Este servidor fica-se pela leitura e por apagar avarias.

**Se um dia gravares flash:** carregador de manutenção ligado durante todo o
processo, e o ficheiro original lido e guardado antes de escreveres o que quer
que seja. Tensão a cair a meio de uma gravação é a forma mais comum de perder
uma centralina.
